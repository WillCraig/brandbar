# Brand Bar

A brandable progress-bar plugin for IntelliJ-based JetBrains IDEs. Fork it, drop in your logo and trail art, and ship a company-skinned progress bar.

This is an original, clean-room project under the MIT License. It is inspired by the *idea* of the [Nyan Progress Bar](https://plugins.jetbrains.com/plugin/8575-nyan-progress-bar) plugin, not a fork of that code, and it does not ship Nyan Cat artwork. Nyan Cat is copyrighted by its creator, Chris Torres (PRguitarman).

v0.1 is tracked in issue #1: a Gradle IntelliJ Platform Plugin 2.x / Kotlin scaffold, a `ProgressBarUI` that paints a runner along a trail, all art loaded from a single theme folder, placeholder original art, a "Fork and brand it" README guide, and CI on `ubuntu-latest`.
